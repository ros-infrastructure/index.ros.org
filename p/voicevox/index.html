voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

cd /path/to/catkin_workspace
catkin build voicevox

For ROS 2 (Python 3.12 or newer is required; python packages are installed with uv)

cd /path/to/colcon_workspace
colcon build --packages-up-to voicevox

voicevox

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

Installation

Build this package.

cd /path/to/catkin_workspace
catkin build voicevox

For ROS 2 (Python 3.12 or newer is required; python packages are installed with uv)

cd /path/to/colcon_workspace
colcon build --packages-up-to voicevox

Optional (Using Docker with GPU acceleration)

VOICEVOX supports Docker deployment with GPU acceleration, which enables significantly faster speech synthesis compared to CPU-only processing.

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）

roslaunch voicevox voicevox_texttospeech.launch

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）

docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。

voicevox

ROS Interface for VOICEVOX (AI speech synthesis)

This package supports both ROS 1 and ROS 2 with the same launch arguments and environment variables. For ROS 2, read roslaunch voicevox voicevox_texttospeech.launch as ros2 launch voicevox voicevox_texttospeech.launch.xml and rosrun as ros2 run.

Quick Start

Choose the deployment pattern that best fits your needs:

# Pattern A: Direct Docker + ROS client (Multi-machine) | 直接Docker + ROSクライアント（マルチマシン）
# Server machine:
docker run --rm --gpus all -p '50021:50021' voicevox/voicevox_engine:nvidia-ubuntu20.04-latest
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern B: ROS-managed Docker + ROS client (Multi-machine) | ROS管理Docker + ROSクライアント（マルチマシン）
# Server machine:
roslaunch voicevox voicevox_texttospeech.launch docker_only:=true
# Client machine:
roslaunch voicevox voicevox_texttospeech.launch host:=<server_ip> port:=50021

# Pattern C: All-in-one (Docker + ROS on same machine) | オールインワン（同一マシンでDocker+ROS）
roslaunch voicevox voicevox_texttospeech.launch use_docker:=true

# Pattern D: Local VOICEVOX without Docker (CPU only) | ローカルVOICEVOX（Dockerなし、CPU版）
# VOICEVOX engine is automatically installed during catkin build
roslaunch voicevox voicevox_texttospeech.launch

Patterns A-C provide GPU acceleration support through Docker. Pattern D runs locally with CPU only. パターンA-CはDockerを通じたGPUによる高速な音声合成をサポート。パターンDはCPUのみでローカル実行。
